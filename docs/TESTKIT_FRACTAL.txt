CRISOL VR v1.0.0 - KIT PARA FRACTAL
===================================

Este kit usa UEVR OpenXR y contiene el perfil importable, el binding nativo
Sense, las herramientas de instalacion y recogida de registros, y la guia
para copiar compilaciones desde Corsario.

1. Extrae el kit en una carpeta local de Fractal.
2. Cierra juego y UEVR. Conserva una copia del perfil anterior e importa
   SOLO el ZIP interior CRToiPrototype-Win64-Shipping.zip con Import Config.
3. Conserva el binding Sense que ya has probado. Para otra instalacion,
   selecciona el layout de la comunidad o sigue la guia detallada inferior.
4. Inicia SteamVR y Crisol, selecciona OpenXR en UEVR e inyecta.
5. Sigue PRUEBA_OTRO_PC.txt, especialmente pausa y coincidencia mira/impacto.

La entrega anterior y los bindings fueron probados por el autor en Fractal.
Las correcciones de pausa y puntero de v1.0.0 se verifican localmente y
requieren comprobarse tambien con el visor.

Para recoger registros desde esta carpeta, en PowerShell normal:
  powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Collect-FractalLogs.ps1
El script guarda un ZIP local y muestra su ubicacion.

Las compilaciones se copian desde \\CORSARIO\ModBuilds\Crisol.
Consulta CORSARIO_FRACTAL.md para configurar otros equipos.
