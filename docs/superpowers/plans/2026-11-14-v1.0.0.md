# Crisol VR v1.0.0 implementation plan

User requested the v1.0.0 release after testing on Fractal, incorporating the
working Sense layout brought back on F:, head-controlled pause menus, and the
subsequently reported pointer offset below/right of the bullet impact.
The landing is the repository README. Existing work in this branch belongs to
the preceding authorized fixes and must be retained.

- [x] Reproduce pause detection without a reflected controller IsPaused method.
  Use GameplayStatics.IsGamePaused with the current world and test resume,
  first-frame transitions and pawn replacement.
- [x] Diagnose the reticle against the actual controller/game aim and UI plane.
  Add a specific failing regression and fix the demonstrated geometry mismatch.
- [x] Compare the tested Sense USB export with the shipped native binding,
  retain its semantics, and document its community selection and fallback.
- [x] Update the English/Spanish GitHub landing, installation, current
  limitations, changelog and v1.0.0 notes using the user's hardware feedback.
- [x] Run the regression suite with Lua 5.4, compile shipped Lua and build and
  verify release assets. Review the two new camera/aim corrections.
- [ ] Commit the complete release sources, publish v1.0.0 with verified assets,
  verify the public tag/downloads and export the final build for Fractal.

OpenXR remains the selected runtime. The user's successful headset test covers
the previous delivery. The new pause/pointer corrections receive local
regression checks and must not be described as headset-verified.
